## 💡 What is Redou? / 什么是红豆？

**Redou (红豆)** is a next-generation long-term memory engine for Large Language Models (LLMs). Unlike traditional RAG (Retrieval-Augmented Generation) which relies on cold vector similarity, Redou introduces **Associative Indexing** and **Emotional Weighting** to give AI a memory that truly "connects" and "feels."

**红豆 (Redou)** 是为大语言模型（LLM）打造的下一代长程记忆引擎。不同于仅依赖向量相似度的传统 RAG 方案，红豆引入了**联想式索引**与**情感权重机制**，赋予 AI 能够“产生连接”且“带有温度”的记忆能力。

---

## ✨ Core Features / 核心特性

| Feature / 特性 | Description / 描述 |
| :--- | :--- |
| **Associative Memory** / 联想式记忆 | Beyond Top-K search; builds a "Knowledge-Emotion Graph" for logical leaps. <br> 超越简单的相似度检索，构建“知识-情感图谱”，实现逻辑跳跃与深度联想。 |
| **Emotional Weighting** / 情感权重 | Prioritizes memories based on frequency, intensity, and user significance. <br> 根据交互频率、情绪强度及用户定义的关键度，优先提取“最相思”的记忆。 |
| **Dynamic Forgetting** / 动态遗忘 | Inspired by the Ebbinghaus curve; consolidates insights and fades noise. <br> 借鉴艾宾浩斯遗忘曲线，自动压缩碎片信息并固化核心知识。 |
| **Privacy-First** / 隐私至上 | Local-first architecture with TEE (Trusted Execution Environment) support. <br> 采用本地优先架构，支持可信执行环境（TEE），守护 AI 的“私人领地”。 |
