**Redou** is a next-generation long-term memory engine for Large Language Models (LLMs). It moves beyond cold vector retrieval to create a memory system that "connects" and "feels."

## ✨ Core Concepts

* 🧠 **Associative Indexing**: Instead of simple similarity, Redou uses a Knowledge-Emotion Graph to enable logical leaps in recollection.
* 🎭 **Emotional Weighting**: Not all data is equal. Redou prioritizes memories based on interaction intensity and user-defined significance.
* ⏳ **Dynamic Forgetting**: Implements a bio-inspired forgetting curve to consolidate core insights while fading background noise.
* 🛡️ **Privacy-First**: Designed for local-first storage and TEE (Trusted Execution Environment) compatibility.
