## 👁️ Vision

**Redou (红豆) aims to build a long-term, associative, and emotionally-weighted external memory engine for LLMs. It is not just about storing data; it allows AI to "think of a person when seeing an object" from fragmented information, much like a human, achieving self-growth of knowledge and deep empathy.**

---

## 🛠️ Technical Roadmap

### A. Associative Indexing `[Xiangsi / 相思]`
* **Research**: Hybrid "Knowledge Graph + Vector" indexing.
* **Goal**: Enable logical/emotional leaps (A → B) beyond simple similarity.

### B. Consolidation & Forgetting `[Wangchuan / 忘川]`
* **Research**: Bio-inspired algorithms (Ebbinghaus Forgetting Curve).
* **Goal**: Clear low-value noise; solidify fragments into structured knowledge.

### C. Emotional Weighting `[Caidie / 采撷]`
* **Research**: Memory storage with `Emotional_Score` (Emotional Tensor).
* **Goal**: Prioritize significant or emotional memories over chronological ones.

### D. Secure Vault & Privacy `[Shoucang / 守藏]`
* **Research**: TEE (Trusted Execution Environment) & encrypted storage.
* **Goal**: Ensure "digital souls" are strictly protected and localized.

### E. Ecosystem Integration `[Jielu / 结缕]`
* **Research**: Unified memory-model interface and protocol.
* **Goal**: Seamlessly knot Redou with LangChain, LlamaIndex, and native LLMs.
