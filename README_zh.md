# 🍒 红豆 (Redou)

> **“红豆生南国，春来发几枝。愿君多采撷，此物最相思。”**

**红豆 (Redou)** 是为大语言模型（LLM）打造的下一代长程记忆引擎。它不仅仅是数据的存储，更是让 AI 拥有“联想”与“共情”能力的记忆中枢。

## ✨ 核心特性

* 🧠 **联想式索引**：超越单纯的向量相似度，构建“知识-情感图谱”，实现类似人类思维的逻辑跳跃。
* 🎭 **情感权重**：并非所有记忆都同等重要。红豆根据交互频率、情绪强度及关键度，优先提取“最相思”的瞬间。
* ⏳ **动态遗忘**：借鉴艾宾浩斯遗忘曲线，自动压缩琐碎信息，将零散对话固化为深层知识。
* 🛡️ **隐私至上**：原生支持本地化存储与可信执行环境（TEE），确保 AI 的“心事”只属于用户。

## 🗺️ 研发路线

- [ ] **阶段 1：种子** - 完成核心存储架构与基础 API 开发。
- [ ] **阶段 2：生长** - 实现仿生遗忘算法，适配 LangChain/LlamaIndex 生态。
- [ ] **阶段 3：收获** - 引入情感共鸣评分系统，支持多智能体记忆共享。
